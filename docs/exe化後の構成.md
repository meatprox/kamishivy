# exe 化後の構成

exe にすると、アプリ本体のコードは見えなくなります。この文書は「どのファイルが exe の中に入り、どれを隣に置くか」です。

このアプリでの呼び方:

- **アプリ本体** … 窓・「次へ」・通信・ログを動かす側。exe に入る
- **UI** … 中央に出る 1枚の画面。`ui` フォルダの `.py` が 1種類
- **CUI** … 画面の順番と引数を書いた Excel（基本は `cui.xlsx`）または CSV
- **土台** … クラス形式の画面が継承する、このアプリ専用の親クラス。exe に含まれる

本体だけを exe にします。CUI から呼び出す画面（`easy` など）は exe に入れず、exe と同じフォルダの `ui/` に後から置きます。開発時のファイル名（`main.py` など）は下の表のための対応です。配布後にそのファイルを開く必要はありません。

## フォルダ構成

```
配布フォルダ/
  kamishivy.exe      … アプリ本体（窓・通信・土台を内蔵。中のコードは見えない）
  LICENSE            … MIT ライセンス
  README.md          … 配布物の案内
  config.ini         … 窓・通信・表示などの設定
  design.ini         … フォントと色（R,G,B の数値）
  cui.xlsx           … 呼び出す UI の順番と引数（cui.csv でも可）
  cui_rei.xlsx       … 例示用 CUI（任意。変数の説明入り）
  sound1.wav         … 次へ音（無くても起動する）
  icon.png           … exe のファイルアイコン用（窓の中には出さない）
  kamishivy.spec     … 作るときに使う。配布しなくてもよい
  docs/
    UIの作り方.md
    簡単なUIの作り方.md
    AI向けUI作成.md
    exe化後の構成.md
  ui/
    easy.py          … あとから足す画面。CUI の1列目の名前と一致
    easy2.py
    check.py
    hyouji.py
    （新しい画面はここに .py を置く）
  logs/              … 起動後にできるログ
```

`ui/base.py` は exe の中に入っているので、後付けの `ui/` には置きません。CUI の1列目に `base` と書かないでください。

## exe に入るもの / 入らないもの

| 入る（アプリ本体。exe の中） | 入らない（exe の隣に置く） |
|---|---|
| 起動の中心（開発時の `main.py`） | `LICENSE` / `README.md` |
| 通信・ログ・デザイン読み込み（開発時の `app/`） | `ui/easy.py` など、CUI から呼ぶ画面 |
| 土台（開発時の `ui/base.py`） | `config.ini` |
| | `design.ini` |
| | `cui.xlsx`（または `cui.csv`） |
| | `sound1.wav`（次へ音。無くても可） |
| | `docs/`（説明書。AI 向けも含む） |
| | `ui/` フォルダそのもの |

exe には ffmpeg と、MIT で再配布しにくい DLL（pyzbar / libzbar など）は入れません。アイコンは exe のファイル用で、アプリの画面には出しません。

## 作り方

```
pyinstaller kamishivy.spec
```

できた `kamishivy.exe` を配布フォルダに置き、上の構成どおり `LICENSE`、`README.md`、`config.ini`、`design.ini`、`cui.xlsx`、`ui/`、`docs/` を同じ場所に並べます。次へ音を使うときは `sound1.wav` も同じ場所です。

メニュー「設定」では、ログの保存先のほかに **予備のログ保存先**（空なら使わない。書けなくてもエラーにしない）、**次へを押したときに音を鳴らす**、**戻るを使わない**、**メニューの次へでコメントを書く** を選べます。記録確認の初期ファイルは、通常のログ保存先の今の記録です。下部の「次へ」は条件を満たしたときだけ進みます。メニューの「次へ」は条件なしで進めます（コメント設定がオンのときだけ入力窓）。

メニュー「表示のカスタマイズ」の「保存・読み出し」タブで、今の見た目を ini に書き出せます。読み出すとその窓の内容が変わり、決定で反映します。デザインのリセットでは、全画面はオフ、押せない「次へ」の文字は薄い灰色に戻ります。

## あとから画面を足す

1. 配布フォルダの `ui/{名前}.py` を追加する
2. 同じフォルダの `cui.xlsx` の1列目にその名前を書く

exe の作り直しは不要です。
