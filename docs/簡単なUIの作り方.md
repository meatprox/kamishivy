# 簡単な UI の作り方

何も知らない人が **画面（UI）** を追加するときに覚える内容です。アプリ本体のプログラムは触りません。exe にすると本体のコードは見えません。

クラス形式まで含めた説明は [UIの作り方.md](UIの作り方.md) です。AI に作らせるときは [AI向けUI作成.md](AI向けUI作成.md) を読み込ませます。

## 画面とは（UI のこと）

**画面** はこのアプリでは **UI** と同じです。窓の中央に出る 1枚で、`ui` フォルダの `.py` が 1種類です。

| 呼び方 | 何を指すか |
|---|---|
| **窓** | アプリ全体 |
| **画面（UI）** | 中央に出る 1枚。`ui/{名前}.py` |
| **アプリ本体** | 窓・「次へ」・通信・ログを動かしている側 |
| **CUI** | 画面の順番と引数を書いた Excel / CSV |
| **次へ** | 窓の一番下のボタン |
| **データ番号** | 通信の相手。`1`〜`9` と `comA` |

`cui` や `get_data` などは、画面のファイルに `def` がありません。実行時に本体が載せるので、そのまま使います。このアプリ専用のものは `import` しません。

`import` してよいのは `tkinter` と標準ライブラリです。`numpy` など別パッケージを足すと、自分の PC（Python あり）では動いても、exe だけの PC では動きません。exe で動くのは、**exe を作ったときに入っているライブラリだけ** です。

## 追加の手順

1. `ui/{名前}.py` を作る
2. CUI の1列目にその名前を書く

CUI の書き方（`♯` の見出し、行を足す画面など）と例（`cui_rei.xlsx`）は [UIの作り方.md](UIの作り方.md) にあります。

`Tk()` は中央の表示域になります。

```python
import tkinter
root = tkinter.Tk()
tkinter.Label(root, text=cui().cell).pack()
root.mainloop()
return 1
```

末尾の `return 1` で、出した時点から次へ可です。

## 関数と変数

| 名前 | 型・戻り | 使い方 |
|---|---|---|
| `cui()` | 情報オブジェクト | `cui().cell` が先頭マス（`str`）。`cui().row` は1行（`list[str]`）。`cui().grid` は全体。数値なら `cui().target`（1つ目、無ければ `None`）と `cui().tare`（2つ目の許容幅） |
| `cui_cell` / `cui_row` / `cui_grid` | 上と同じ中身 | `cui()` を呼ばず名前のまま読むとき |
| `get_data(番号)` | 文字または `None` | `get_data(1)`。生の文字は `get_data(1, raw=True)` |
| `send_data(番号, 文字)` | 成功なら真 | `send_data(1, "D01\r\n")` |
| `write_log(内容)` | なし | ログへ残す。数値でも配列でも辞書でも可 |
| `done()` | なし | あとから次へ可にする。最初からなら `return 1` |
| `design` | 辞書 | 色・フォント。`design["font"]` / `design["background"]` / `design["text"]` |
| `parse_number(文字)` | `float` または `None` | 足し算の前に文字を数値へ |

キーパッド・時間・ファイルパス・表のスクロールは [UIの作り方.md](UIの作り方.md) にあります。
